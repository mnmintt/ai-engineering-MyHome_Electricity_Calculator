

Architecture Decision Record (ADR)

| Decision | Requirement / Constraint | Alternatives Considered | Selected Option | Trade-off Accepted |
|---|---|---|---|---|
| Application Structure | FR5, FR8, NFR4 — The system must allow users to access the Estimated Bill Calculator and Home Energy Calculator independently through one application. | 1. Combine both calculators into one workflow. 2. Develop two separate applications. 3. Provide two independent features under one web application. | Use one web application with a shared interface that provides two separate features: Estimated Bill Calculator and Home Energy Calculator. | Users can access both features from one application. However, each feature requires its own input form and calculation process. |
| Bill Calculation Engine | FR5, RAI2 — The Estimated Bill Calculator must calculate electricity bills using the selected tariff type, user inputs and documented tariff assumptions. | 1. Use a fixed electricity rate. 2. Use documented tariff rates and calculation rules. 3. Use AI to generate estimated bill amounts. | Use a dedicated Bill Calculation Engine that receives tariff selection and billing inputs, then calculates the estimated bill using documented tariff data and rules. | Tariff information must be checked and updated when necessary. The calculated amount is an estimate and may differ from the actual TNB bill. |
| Energy Calculation Engine | FR2, FR3, NFR1 — The Home Energy Calculator must calculate electricity consumption based on appliance information. | 1. Use AI to estimate electricity consumption. 2. Use a mathematical calculation formula. 3. Allow users to enter their own estimated consumption. | Use a dedicated Energy Calculation Engine that calculates electricity consumption using appliance wattage, quantity and daily usage hours. | Users must provide appliance information. The accuracy of the results depends on the accuracy of the information entered. |
| Usage Dashboard | FR4, NFR2 — The system must display understandable electricity consumption statistics for the household. | 1. Display only total household consumption. 2. Display statistics by appliance, room, floor and household. 3. Display results only as text reports. | Provide a Usage Dashboard that displays estimated electricity consumption by appliance, room, floor and household using the results from the Energy Calculation Engine. | Detailed statistics help users understand their electricity usage, but require the system to organize and calculate the data correctly. |
| AI Assistant | FR6, RAI1, RAI4 — The system must provide relevant energy-saving recommendations and answer household energy questions using available information. | 1. Provide only fixed energy-saving tips. 2. Use an AI assistant with household data and relevant energy-saving information. 3. Allow AI to generate answers without verified calculation results. | Provide an AI Assistant within the Home Energy Calculator to generate energy-saving recommendations and answer household energy questions. The assistant uses available household data, relevant energy-saving information and verified calculation results. | AI responses may not always be suitable or accurate. Recommendations and numerical answers must be checked against available information and calculation results. |
| What-if Simulator | FR7 — The system must allow users to compare electricity consumption before and after changing appliance usage assumptions. | 1. Provide general energy-saving tips only. 2. Allow users to change appliance usage hours or quantities and recalculate consumption. 3. Use AI to predict guaranteed electricity savings. | Provide a What-if Simulator within the Home Energy Calculator. It uses the Energy Calculation Engine to compare original and adjusted appliance usage scenarios. | Users can explore possible energy savings, but simulated results do not guarantee actual real-world savings. |
| Supporting Data Sources | FR5, FR6, RAI2 — The system requires reliable tariff information and relevant energy-saving knowledge. | 1. Hard-code all tariff and energy-saving information. 2. Use documented tariff information and relevant energy-saving references. 3. Allow AI to determine tariff rates and energy-saving information without verification. | Use a Tariff Data Source to support the Bill Calculation Engine and an Energy Knowledge Source to support the AI Assistant. | External information may change or become outdated. The system must document its sources and identify assumptions when information is incomplete. |
